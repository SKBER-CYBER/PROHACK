## 🐛 Troubleshooting

### ❌ Error: `requests not installed`

**Fix:**
```bash
pip install requests httpx
```

---

### ❌ Error: `Missing wget`

**Fix:**
```bash
pkg install wget curl -y
```

---

### ❌ Error: `pip: command not found`

**Fix:**
```bash
pkg install python -y
python3 -m pip install --upgrade pip
```

---

### ❌ Error: `python2 not found`

**Fix:**
```bash
pkg install python2 -y
```

---

### ❌ Error: `git clone failed`

**Fix:**
```bash
git config --global http.postBuffer 524288000
git clone https://github.com/SKBER-CYBER/PROHACK
```

---

### ❌ Error: `bs4 module not found`

**Fix:**
```bash
pip install beautifulsoup4
```

---

### ❌ Error: `mechanize install failed`

**Fix:**
```bash
pkg install libxml2 libxslt -y
pip install mechanize
```

---

### ❌ Error: `Proxy detected`

**Fix:**

- ❌ Turn off **HTTPCanary**
- ❌ Turn off **VPN**
- ❌ Turn off **Proxy apps**
- ✅ Re-run tool

---

### ❌ Error: `SSL MITM detected`

**Fix:**

```
Settings → Security → Trusted Credentials → User
→ Remove suspicious certificates
```

---

### ❌ Error: `Storage permission denied`

**Fix:**

```
Settings → Apps → Termux → Permissions → Storage ✅
```

---

### ❌ Error: `No internet connection`

**Fix:**
```bash
ping google.com
```

Internet check করো, তারপর re-run।
